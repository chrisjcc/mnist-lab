🌐 Architecture Note: Web Portal vs. Python Streamlit App

  • Netlify Role (Static CDN & Portal): Netlify serves this fast, lightweight web portal, documentation, and model performance metrics over its global edge CDN.
  • Why 404 Occurred Previously: Netlify is a Jamstack static host that serves pre-built HTML/CSS/JS. It does not parse Dockerfiles or run long-running Python/Streamlit servers. Connecting the repository without an index.html resulted in a 404 page.
  • Where the Streamlit App Runs: Streamlit requires an active Python runtime and WebSocket daemon to execute PyTorch neural network forward passes. It is deployed via the included Dockerfile on Hugging Face Spaces or Streamlit Community Cloud.
